I build ML and LLM systems that have to hold up in production: models that answer in under 30ms, pipelines that are safe to re-run, and LLM tools that stay cheap as they scale.

Over **4+ years**, I've worked across **gaming** (recommendation systems, game data quality, data pipelines), **computer vision** (models running in 100+ installations worldwide), and **LLM automation** (agentic parsers, RAG chatbots, content pipelines), plus freelance work in **energy** and **sports**.

My rule of thumb: if plain code can handle it, don't call an LLM. That means fewer hallucinations, lower costs, and fewer surprises in production.

Currently at **Bragg Gaming** in Rotterdam, building data pipelines and LLM tooling for game data.
